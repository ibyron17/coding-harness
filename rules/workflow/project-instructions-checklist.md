# 프로젝트 CLAUDE.md 체크리스트 (rules/workflow/project-instructions-checklist.md)

## 프로젝트 CLAUDE.md에 정의해야 할 항목 (체크리스트)

각 프로젝트 루트의 CLAUDE.md에는 최소한 다음을 정의한다:
1. 프로젝트 개요와 목적 (도구가 하지 말아야 할 것 포함)
2. 아키텍처: 레이어/모듈 구성과 각 책임
3. 성능: 이 프로젝트의 실제 병목과 최적화 우선순위
4. 빌드/검증 명령: 실행, 테스트, lint/format, type check의 실제 명령
5. 프로젝트 고유 컨벤션 (커밋 형식, 브랜치 규칙 등이 있다면)
